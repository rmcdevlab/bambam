## Approved scope

Replace the Go/Gin runtime with server-only TypeScript in the existing Next.js application. Preserve PostgreSQL data/schema, public API paths/shapes, RMC SSO/session behavior, role/permission rules, repair workflows, settings, photos, QR labels and recurring maintenance.

The owner approved starting the migration, then explicitly requested finishing every migration stage continuously. The owner subsequently instructed stopping verification and removing unnecessary files. Per-stage pauses and further testing were waived for this migration only.

## Implementation

- Native Route Handlers and server services for auth, repair and settings under `frontend/src/server/`.
- Parameterized PostgreSQL queries and migrations under `frontend/db/`; the Node runner preserves existing Goose migration history.
- Persistent photo storage plus interval/external maintenance scheduling.
- One Next.js runtime; the Go directory and API rewrites are removed.
- Existing private config migrated into ignored `.env.local`; original config retained in ignored `.env.legacy.local`.
- Next.js patched within the existing 16.4 line to 16.4.6.
- Large generated caches/results and obsolete proposals removed; automatic browser recording disabled and future test output/cache cleaned on exit.

API contracts and approved business rules are unchanged. No production deployment, live-provider SSO UAT, commit, tag or push is claimed. Completion notes and verification limits: `CR-056-completion.md`.
