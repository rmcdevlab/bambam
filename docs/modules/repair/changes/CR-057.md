## What changes

ตอนนี้ถ้ากรอกฟอร์มค้างไว้แล้วเปลี่ยนหน้า แอพจะแสดง popup ของตัวเอง แต่ถ้า refresh จะเป็น alert box ของเบราว์เซอร์ เจ้าของต้องการให้เหมือนกันทั้งหมด
เบราว์เซอร์ไม่ยอมให้แสดง popup ของแอพตอน refresh หรือปิดแท็บ เจ้าของจึงเลือกให้**ทุกกรณีใช้ alert box ของเบราว์เซอร์**
และให้**ทุก form รวมถึง dialog** เตือนแบบเดียวกัน

1. Leaving a form that has unsaved input always uses the **browser's native dialog**:
   - refresh, close tab, typed URL: `beforeunload` (already the case, wording is fixed by the browser)
   - in-app links, sidebar/nav, back buttons in the app, browser Back: `window.confirm(...)`
   - closing a form dialog/sheet (✕, Esc, click outside, ยกเลิก) with input entered: `window.confirm(...)`
2. The custom `AlertDialog`s "ทิ้งข้อมูลที่กรอกไว้?" (S03/S10) and "ออกโดยไม่บันทึก?" (S24) are removed.
3. One shared hook (`components/shared/use-unsaved-guard.ts`, replaces `use-discard-guard.ts`) and one confirm text for all forms:
   `ข้อมูลที่กรอกไว้ยังไม่ได้บันทึก ต้องการออกจากหน้านี้หรือไม่?` (dialogs: `…ต้องการปิดหน้าต่างนี้หรือไม่?`).
   The browser shows its own OK/Cancel buttons. Their text cannot be changed.
4. Empty or untouched form → leave/close silently (unchanged rule).

## Why

The owner wants one consistent warning on every form. A custom popup cannot be shown on refresh or tab close (browser restriction), so the native dialog is the only option that can be the same in every case.
